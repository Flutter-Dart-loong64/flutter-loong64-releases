# Flutter SDK Build v2026.05.20.1

This release records native LoongArch64/Loong64 builds for Flutter SDK, Dart SDK, and Flutter Engine only. Application projects are not part of this release.

This release supersedes `loong64-20260520`. The earlier release carried `15f302...` Linux GTK engine artifacts while the Flutter toolchain and Dart frontend used `ae9f14...`, and it did not enable fontconfig in the published engine. This build republishes the SDK with matching `ae9f14...` engine runtime and `--enable-fontconfig`.
